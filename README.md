# Coding Interview Prep

Structured Python solutions for coding interview practice, organized by algorithmic pattern and focused on clean implementation, reasoning, and time/space complexity.

## Purpose

This repository tracks my preparation for technical interviews through pattern-based problem solving. The goal is not just to collect accepted solutions, but to build fluency in recognizing common problem types and implementing them clearly.

## Solution Format

Most solutions include:

- Problem name
- Pattern / category
- Core idea
- Time complexity
- Space complexity
- Python implementation

Example:

```python
"""
Problem: Group Anagrams
Pattern: Hash Map / Sorting
Time: O(n * k log k)
Space: O(n * k)

Idea:
Use the sorted version of each word as a canonical key.
Words with the same key belong to the same anagram group.
"""
```
